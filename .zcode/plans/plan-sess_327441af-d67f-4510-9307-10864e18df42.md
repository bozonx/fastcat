# Plan: Make `pnpm check` green

## Diagnosis (confirmed, not assumed)

`pnpm check` fails on exactly two independent issues; everything else is already green (static + 6708 unit + 137 integration + full Rust suite + clippy + fmt).

**Issue A — `golden:web` wrongly inside the merge gate.**
`pnpm check:ui` runs `test:golden:web`, but per `scripts/ci.sh` + AGENTS.md, `golden` is an explicitly **non-gate, GPU-only** tier ("GPU-fragile under SwiftShader, so they are not wired into CI"). In this env WebGPU's adapter is `google/swiftshader` and the Dawn instance dies on real use (`OperationError: A valid external Instance reference no longer exists`), so all 44 scenes render black frames. This is environment, not code. **Already fixed** in `package.json` (removed `test:golden:web` from `check:ui`).

**Issue B — 15 e2e failures. Two root causes:**
1. **Stale tick literals (9 persistence-only specs).** Commit `c5836e479` ("remake time units") changed the canonical scale from microseconds (`US_PER_SEC=1e6`) to Premiere ticks (`TICKS_PER_SECOND=254_016_000_000`) — **254 016× denser**. Production code was migrated; e2e specs were not. Old literals like `-400_000`, `1_200_000`, `500_000` (formerly meaningful as µs) are now sub-frame (1 frame@30fps = `8_467_200_000` ticks) → `quantizeDeltaTicksToFrames` rounds them to 0 → trim/move/marker/text-clip commands become **no-ops** → `waitForTimelineDoc` predicates time out. **Production is correct** (proven: trim with a frame-scale value persisted exactly).
2. **WebGPU-dependent specs (5 specs).** `journey-main-editing`, `journey-persistence`, `text-clip-render-export` (×2) run a full export pipeline; `blur-past-edges` (×2) compares rendered bounding boxes. With WebGPU broken here they false-fail. `blur-past-edges` already has a `probeWebGpu` + `test.skip` guard (lines 181-182); the others don't.

`clip-audio` is a special persistence-only case: its `100_000 * TICKS_PER_MILLISECOND` (100s fade) is correctly clamped to the 1.0s `audio-sine.wav` clip duration — **intentional** prod behavior (`properties.ts:205`, "Clamp to the current clip duration to avoid invalid envelopes"). Test expectation is unrealistic; test must change.

## Approach (per user decisions)
- Render specs → **add `probeWebGpu` + `test.skip` gate** mirroring `blur-past-edges:181-182`.
- Tick literals → **convert via existing helpers** (`secondsToTicks`/`framesToTicks` from `~/utils/time/ticks`), preserving original intent (e.g. `-400_000` µs = 0.4s → `secondsToTicks({seconds:0.4})`).
